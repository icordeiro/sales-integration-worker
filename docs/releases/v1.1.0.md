# Sales Integration Worker v1.1.0

## Observabilidade e operação

A v1.1.0 amadurece a operação do SIW sem alterar o fluxo central de exportação homologado na v1.0.0.

Esta versão adiciona diagnóstico operacional, health check, CLI unificada, logs estruturados e um modo demonstração seguro para avaliação do projeto sem infraestrutura externa.

## Destaques

### Health Check

Novo endpoint:

```text
GET /api/health
```

O SIW passa a monitorar PHP, SQLite, PostgreSQL, configuração SFTP, storage, lock do worker e histórico de exportações.

O dashboard diferencia:

- `healthy`: operação normal;
- `degraded`: infraestrutura disponível com atenção operacional;
- `unhealthy`: indisponibilidade ou configuração inválida.

### CLI unificada

Novos comandos:

```bash
php bin/console status
php bin/console doctor
php bin/console migrate
php bin/console export:daily
```

`status` realiza verificações leves. `doctor` executa diagnóstico profundo, incluindo autenticação SFTP real, sem upload.

### Logs estruturados

Eventos técnicos agora podem ser gravados em JSON Lines:

```text
storage/logs/siw-YYYY-MM.log
```

O log inclui contexto como execution ID, data do movimento, tipo, duração, status, arquivo e falha, sem registrar credenciais.

O runner do Windows Task Scheduler também utiliza rotação mensal.

### Demo Mode

Agora é possível demonstrar o SIW sem ERP ou SFTP:

```dotenv
APP_DEMO=true
```

```bash
php bin/console demo:seed
php -S 127.0.0.1:8080 -t public
```

O dataset inclui execuções normais, falha simulada, reenvio e reprocessamento vinculados às respectivas origens.

No modo demo, acesso ao PostgreSQL, SFTP, reenvio e reprocessamento reais ficam bloqueados.

Para recriar o dataset:

```bash
php bin/console demo:reset
```

## Compatibilidade

A atualização é retrocompatível com a v1.0.0:

- não altera a semântica da exportação diária;
- não exige reinstalação do Task Scheduler;
- não exige nova migration nesta release;
- `APP_DEMO` assume `false` quando não configurado.

## Upgrade

Depois de atualizar o código:

```bash
composer install
composer dump-autoload -o
php bin/console doctor
vendor/bin/phpunit --configuration phpunit.xml.dist
```

No Windows:

```powershell
vendor\bin\phpunit --configuration phpunit.xml.dist
```

## Segurança

Nenhuma credencial deve ser versionada. Continue utilizando `.env` local e um usuário PostgreSQL dedicado somente para leitura.

O modo demonstração foi projetado para avaliação local e screenshots seguros; ele não substitui autenticação ou controles de acesso para exposição pública do dashboard.
